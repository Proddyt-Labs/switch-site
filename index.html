Como instalar

Use o botão Baixar do app para abrir a página de releases e escolha o arquivo do seu sistema. Troque <app> pelo nome do executável (por exemplo printcraft).

Windows: instalador

<app>-windows-x64-setup.exe

Instala para o seu usuário em %LOCALAPPDATA%\Programs\Proddyt Studio\. Não precisa de administrador.

Windows: portátil

<app>-windows-x64-portable.zip

Extraia em qualquer pasta e execute. Nada é instalado no sistema.

Linux e macOS

<app>-<sistema>.tar.gz

Versão portátil: extraia o arquivo e execute o binário.

Atualizações

A cópia instalada ou portátil no Windows consulta as releases do app no GitHub ao abrir e pergunta: Atualizar, Agora não ou Ignorar esta versão.

Sobre

Os apps são forks da suíte de código aberto ArtCraft, compilados e publicados automaticamente pelo GitHub Actions. O Proddyt Studio faz parte do Proddyt Labs.
