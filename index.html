Proddyt Switch

Suíte de apps desktop da Proddyt Labs. Cada app é um fork dos Crafting Apps (ArtCraft) — reimplementações open-source em Rust de ferramentas como Acrobat, Photoshop e Excel — com features próprias, sincronia diária com o projeto original e build automático pra Windows, Linux e macOS.

Apps

Como funciona

Portátil = testar

Zip/tar que roda sem instalar. Serve pra testar a versão mais nova da main antes de usar no dia a dia.

Instalador = usar

No Windows, <app>-windows-x64-setup.exe: instala só pro usuário (sem admin), com atalho no menu Iniciar e opcional na área de trabalho.

Release automática

Todo push na main (e todo dia depois da sincronia) gera uma Release v<versão>-labs.<data>.<commit> com os pacotes dos 3 sistemas.

Sincronia com o original

Todo dia o fork puxa a main do projeto original (storytold). Se houver conflito com uma feature nossa, a sincronia para e avisa — nada é sobrescrito.

Usar com uma IA (MCP)

Todo app traz um servidor MCP no CLI que vem junto no pacote. Exemplo no Claude Code:

claude mcp add print-labs -- "C:\caminho\printcraft-cli.exe" mcp --root "C:\Meus PDFs"

O --root limita a IA àquela pasta.
